# Registros de decisión (ADR)

Un ADR por decisión **difícil de revertir**, numerado y en su propio archivo, con
contexto, decisión y consecuencias —las buenas y las malas—. Un ADR no se
reescribe: si la decisión cambia, se emite uno nuevo que la reemplaza y el
anterior queda marcado como reemplazado.

Las decisiones que se revierten sin coste alto no necesitan ADR: viven como
restricción en `AGENTS.md` o como dato en el documento que las aplica. Por eso
aquí hay un solo registro aunque el repositorio haya tomado varias decisiones
técnicas.
